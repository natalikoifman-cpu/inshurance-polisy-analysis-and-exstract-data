# סקיל 12 — שליפה מודעת-הקשר: מצב הפונה + אסוציאציות + ערך המידע

## הבעיה
שליפה לפי מילים בלבד מתעלמת משני דברים: **המצב** של הפונה (בהול מול רגוע —
אותן מילים, צורך שונה לגמרי), ו**הקשרים** בין פרטי מידע (שאלה על נושא X
צריכה להעלות גם את מה שקשור אליו, גם אם המילים שונות).

## איך זה עובד
1. **מודעות למצב** — מזהים מהניסוח את מצב הפונה (רגוע / מתוסכל / דחוף)
   ומעדיפים את הזיכרונות/הקטעים שמתאימים לאותו מצב: פנייה בהולה מקבלת
   קודם את ההיסטוריה הבהולה (התקלה הקודמת, ההסלמה הקודמת), פנייה רגועה —
   את התשובות הרגילות.
2. **הרחבה אסוציאטיבית** — שליפה היא לא נקודה בודדת: מהממצאים המובילים
   ממשיכים גם אל מה שקשור אליהם (אותו [ישות/מוצר/נושא]), בעדיפות נמוכה
   יותר — כך שההקשר מגיע בלי להציף.
3. **ערך המידע ולא דמיון מילים** — בשאלות עם השלכות, מדרגים כל פריט לפי
   "כמה הידיעה הזו משנה את התשובה הנכונה?" ולא לפי כמה מילים משותפות יש
   לו עם השאלה. פריט שמשנה את הפעולה גובר על פריט שרק דומה בניסוח.

## בלוק מוכן להדבקה

```
כלל שליפה מודעת-הקשר:
- לפני מענה לפונה מזוהה, זהה את מצבו מהניסוח: מילים כמו "דחוף",
  "!!", "שוב אותה בעיה" = מתוסכל/בהול; ניסוח רגוע = רגיל.
- בפנייה בהולה — פתח בהמשכיות, לא בשאלון: "אני רואה שזו הפעם
  השנייה — מצטער על כך, בוא נסגור את זה עכשיו."
- כשאתה נעזר בעובדות שמורות או במסמכים, בחר את הפריטים לפי שלושה
  שיקולים, בסדר הזה:
  1. האם הפריט משנה את התשובה או הפעולה הנכונה? (ולא רק דומה במילים)
  2. האם הוא מתאים למצב הפונה (בהול ← ההיסטוריה הבהולה)?
  3. האם הוא קשור ישירות לנושא (אותו [מוצר/תיק/נושא])? צרף גם את
     הקשור — אבל הזכר בתשובה רק את 1–2 הפריטים הרלוונטיים ביותר.
- פריט שנראה מיושן — אמת מול הפונה לפני שאתה מסתמך עליו.
ללא אינטרנט: השליפה נעשית רק מהעובדות והמסמכים שסופקו לסוכן —
לעולם לא מחיפוש באינטרנט.
```

## בדיקה לפני השקה
שמרו לפונה בדיקה זיכרון משיחה רגועה אחת ומשיחה בהולה אחת. שאלו שאלה דומה
פעמיים — פעם בניסוח רגוע ופעם כמקרה חירום. הסוכן עובר רק אם הניסוח הבהול
מעלה קודם את ההקשר הבהול, ושתי ההרצות עקביות בחזרה עליהן.
