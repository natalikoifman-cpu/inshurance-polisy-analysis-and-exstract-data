# סקילים עצמאיים — לכל תחום ולכל תרחיש (ללא אינטרנט)

תיקייה זו היא עותק גנרי של 12 הסקילים, שנבנה לפי שלושה עקרונות:

1. **כל סקיל עומד בפני עצמו** — אין תלות בסקילים אחרים, בקונקטור, בקישורים או
   בכלים חיצוניים. פותחים קובץ אחד, מעתיקים את הבלוק, מדביקים ב-Instructions
   של הסוכן ב-Copilot Studio — וזה עובד.
2. **מתאים לכל usecase** — אין כאן ביטוח, מכירות או שירות. כל מקום שבו רואים
   סוגריים מרובעים `[כך]` — מחליפים בפרטים של התחום שלכם.
3. **ללא חיפוש באינטרנט** — כל בלוק כולל כלל מפורש: הסוכן משתמש אך ורק במידע,
   במסמכים ובכללים שסופקו לו. לעולם לא באינטרנט ולא ב"ידע כללי" של המודל.

## איך משתמשים

- צריך סוכן מלא? מדביקים כמה בלוקים שרוצים, זה אחרי זה, באותו Instructions.
- צריך לתקן התנהגות אחת? מדביקים רק את הסקיל שפותר אותה.
- כל קובץ מסתיים ב"בדיקה לפני השקה" — כך יודעים שהסקיל באמת נקלט.
