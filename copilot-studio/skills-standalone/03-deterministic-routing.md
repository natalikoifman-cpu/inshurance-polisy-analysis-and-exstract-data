# סקיל 3 — ניתוב לפי חוקים: החוקים מחליטים, ה-AI מדבר

## הבעיה
"אם המקרה מסוג X ← מסלול א', אם Y ← מסלול ב'." כשה-AI מקבל החלטות כאלה הוא
מנחש, וכל הרצה יכולה להסתיים במסלול אחר. חוק שנכתב כחוק הוא צפוי, ניתן
לבדיקה, ותמיד זהה.

## איך זה עובד
אחרי שכל הפרטים נאספו, **השלב הבא נבחר לפי תנאים פשוטים** — ב-Copilot Studio
משתמשים ב-Topics עם תנאים (Add node ← Add a condition). ה-AI לעולם לא בוחר
את הענף; הוא רק מנהל את השיחה בתוך הענף שנבחר.

## דוגמה למערכת חוקים (החליפו בערכים שלכם)

```
אם [נושא] = [ערך א'] ← המשך ב-[Topic א']
אם [נושא] = [ערך ב'] וגם [שדה נוסף] = [ערך] ← המשך ב-[Topic ב']
אם [נושא] = [תלונה / מקרה רגיש] ← העבר לנציג אנושי
אחרת ← שאל שאלת הבהרה
```

## בלוק מוכן להדבקה

```
כלל ניתוב:
אתה לעולם לא מחליט בעצמך על המסלול העסקי. אחרי שהטופס הושלם, פעל
אך ורק לפי טבלת החוקים הבאה, לפי הסדר, והמשך רק בענף הראשון שתנאיו
מתקיימים במלואם:
1. אם [תנאי] ← [מסלול/פעולה]
2. אם [תנאי] וגם [תנאי] ← [מסלול/פעולה]
3. אחרת ← שאל שאלת הבהרה אחת קצרה.
אם אף חוק לא מתאים — אל תבחר מסלול "לפי תחושה"; שאל.
ללא אינטרנט: ההחלטה מתבססת רק על החוקים שכאן ועל פרטי הפנייה —
לא על חיפוש באינטרנט ולא על ידע כללי.
```
